Changelog 📝

Principais versões e mudanças do EcoSense.

2.1.0 — Front embarcado oficial

Interface da Luísa integrada diretamente ao servidor do ESP32, API local, Performance, Logs, configurações, OTA e gráficos sem dependência de internet.

2.0.0 — ESP32 servidor autônomo

Web Server, API local, FreeRTOS, histórico 24h, logs, NVS, OTA, Light Sleep, interrupção e controle dos dois atuadores via D4184.

1.x — Arquitetura externa

Backend PHP, PostgreSQL e MQTT permanecem disponíveis como integração complementar, mas não são necessários para a operação local do TDE.
